# e-plantShopping

## Paradise Nursery — Online Plant Shopping Application

Welcome to **Paradise Nursery**, an online plant shopping application built with React. This project allows user to explore a variety of houseplants and add their favorite plants to a shopping cart.

### Features

- A landing page introducing Paradise Nursery.
- Navigation between the home page, product listing page, and shopping cart.
- Plant listings organized into different categories, such as aromatic plants and medicinal plants.
- Plant cards displaying images, names, descriptions, and prices.
- Add-to-cart functionality.
- Shopping cart with quantity increase and decrease controls.
- Delete plants from the cart.
- Automatic calculation of item subtotals and the total cost.
- Continue Shopping and Checkout buttons.

### Technologies Used

- React
- JavaScript
- HTML
- CSS

### Project Objective

The objective of this project is to demonstrate React development skills, component-based UI design, state management, and dynamic shopping cart functionality.
